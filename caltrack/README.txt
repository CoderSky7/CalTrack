CALTRACK — NETLIFY UPLOAD PACKAGE

1. Extract CalTrack-Netlify.zip.
2. Upload the CalTrack folder to Netlify using its manual upload option.
   Choose the folder containing index.html, style.css, and app.js.
3. No build command, dependencies, backend, or API keys are needed.

This package contains the current meal journal with food search, custom
foods, water tracking, meal notes, food-group overview, and meal planner.

Data is saved in each visitor's browser. Existing data on the ChatGPT Site
will not automatically transfer to the new Netlify address. Clearing browser
data removes saved records. This static copy does not include the original
Site's sign-in gate; access is controlled by your Netlify hosting settings.
